## 1. Назначение и область применения программы

### 1.1. Назначение программы

**DotaTrener** — это кроссплатформенное мобильное приложение (веб + Android), предназначенное для поиска, выбора и взаимодействия с тренерами по компьютерной игре Dota 2. Программа обеспечивает:

- Автоматизированный подбор тренеров на основе рейтинга, специализации и стоимости услуг;
- Просмотр статистики игроков (матчи, герой, KDA, GPM/XPM, нетворс);
- Внутренний мессенджер для общения между игроком и тренером;
- Управление услугами и видео-материалами для тренеров;
- Интеграция со Steam API и Stratz API для получения данных о матчах.

### 1.2. Область применения

Программа предназначена для использования в сфере киберспортивного коучинга. Целевая аудитория:

- **Игроки Dota 2** —寻找 тренеров для улучшения навыков игры;
- **Тренеры (коучи)** —提供 услуги по разбору матчей, обучению, продвижению своих услуг;
- **Администраторы** — модерация заявок тренеров.
