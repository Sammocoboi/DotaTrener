## 1. Наименование программы

**DotaTrener** (сокращённо: Dota Trainer)  
**Версия:** 1.0.0  
**Платформы:** Web (React Native Web), Android

---

## 2. Назначение программы

**DotaTrener** — это кроссплатформенное мобильное приложение для поиска, выбора и взаимодействия с тренерами по компьютерной игре Dota 2. Программа предназначена для автоматизации процесса коучинга, обеспечивая интеграцию с игровыми API (Steam, Stratz), внутренний мессенджер и инструменты управления услугами для тренеров.

---

## 3. Функции программы

### 3.1. Основные функции

| № | Функция | Описание |
|---|---------|----------|
| 1 | Авторизация через Steam | Аутентификация пользователей через Steam OpenID |
| 2 | Профиль игрока | Просмотр и редактирование профиля (ник, аватар, MMR, ранг) |
| 3 | Просмотр матчей | Список последних 20 матчей с детальной статистикой |
| 4 | Каталог тренеров | Поиск тренеров с фильтрацией по рейтингу, цене, специализации |
| 5 | Услуги тренера | Управление списком услуг для тренеров (CRUD) |
| 6 | Чат | Внутренний мессенджер для общения между игроком и тренером |
| 7 | Отзывы | Оставление отзывов о тренерах (1-5 звёзд) |
| 8 | Видео | Загрузка и просмотр видео-обзоров тренеров |
| 9 | Мета героев | Статистика по героям (win rate, pick rate, билды) |
| 10 | Администрирование | Рассмотрение заявок тренеров администратором |

### 3.2. Экранные формы

| Экран | Назначение |
|-------|------------|
| index | Главный экран с навигацией по разделам |
| profile | Профиль пользователя с настройками |
| coaches | Список всех тренеров |
| coach-detail | Страница тренера с услугами, видео, отзывами |
| matches | Список матчей игрока |
| match-detail | Детальный просмотр матча |
| chat | Экран чата с тренером |
| conversations | Список активных бесед |
| my-services | Управление услугами (для тренеров) |
| heroes | Список героев Dota 2 |
| hero-meta | Мета-статистика героев |
| steam-link | Привязка аккаунта Steam |
| stratz-token | Ввод Stratz API токена |
| admin-applications | Панель администратора |

**Сервер:**

- Web-браузер (последняя версия)

- Протокол: HTTP/HTTPS
- Порты: 80 (HTTP), 443 (HTTPS)
- Пропускная способность: 1 Мбит/с+

## 5. Входные и выходные данные

### 5.1. Входные данные

| Данные | Источник | Формат |
|--------|----------|--------|
| Данные Steam OpenID | Steam API | JSON |
| Stratz API токен | Пользователь | Строка (JWT) |
| Текст сообщения | Пользователь | Unicode |
| Данные матча | Stratz GraphQL API | JSON |
| Файл видео | Пользователь | MP4/WebM/MOV/MKV (макс. 600 МБ) |
| Аватар | Пользователь | JPEG/PNG (макс. 5 МБ) |

### 5.2. Выходные данные

| Данные | Назначение | Формат |
|--------|------------|--------|
| Профиль игрока | Отображение на экране | JSON |
| Список матчей | Просмотр статистики | JSON |
| Список тренеров | Каталог | JSON |
| Сообщения чата | Общение | JSON |
| Список услуг | Управление | JSON |

### 5.3. Внутренние данные

| Объект | Описание |
|--------|----------|
| Player | Профиль игрока (Steam ID, MMR, ранг, аватар) |
| Coach | Профиль тренера (специализация, рейтинг, bio) |
| CoachService | Услуга тренера (название, цена, длительность) |
| CoachVideo | Видео тренера (файл, длительность, цена) |
| CoachReview | Отзыв о тренере (оценка 1-5, текст) |
| Conversation | Беседа между игроком и тренером |
| Message | Сообщение в чате |
| Match | Матч игрока (герой, результат, статистика) |
| Hero | Герой Dota 2 (справочник) |
| Item | Предмет Dota 2 (справочник) |
| Ability | Способность Dota 2 (справочник) |

## 6. Интерфейсы взаимодействия

### 6.1. Клиент-Сервер

| Метод | URL | Описание |
|-------|-----|----------|
| GET | /api/coaching/profile/ | Получение профиля |
| PATCH | /api/coaching/profile/ | Обновление профиля |
| GET | /api/coaching/my-matches/ | Список матчей |
| GET | /api/coaching/match/{id}/ | Детали матча |
| GET | /api/coaching/coaches/ | Список тренеров |
| GET | /api/coaching/coaches/{id}/ | Детали тренера |
| POST | /api/coaching/become-coach/ | Заявка на тренера |
| GET | /api/coaching/conversations/ | Список бесед |
| POST | /api/coaching/conversations/ | Создание беседы |
| POST | /api/coaching/conversations/{id}/ | Отправка сообщения |
| GET | /api/coaching/my-services/ | Список услуг |
| POST | /api/coaching/my-services/ | Создание услуги |
| PATCH | /api/coaching/my-services/{id}/ | Обновление услуги |
| DELETE | /api/coaching/my-services/{id}/ | Удаление услуги |
| POST | /api/coaching/upload-avatar/ | Загрузка аватара |
| POST | /api/coaching/upload-video/ | Загрузка видео |
| POST | /api/coaching/set-stratz-token/ | Сохранение токена Stratz |
