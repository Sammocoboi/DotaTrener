## 3. Алгоритмы ключевых функций

### 3.1. Алгоритм авторизации

```
1. Клиент: Нажатие "Войти через Steam"
2. Клиент → Сервер: GET /api/auth/steam/login/
3. Сервер → Steam: Перенаправление на OpenID
4. Steam → Сервер: Callback с параметрами
5. Сервер: Создание/обновление профиля
6. Сервер → Клиент: JWT токен + steam_id
7. Клиент: Сохранение токена в SecureStore/localStorage
```

### 3.2. Алгоритм загрузки матчей

```
1. Клиент → Сервер: GET /api/coaching/my-matches/
2. Сервер: Проверка Stratz токена
3. Сервер → Stratz API: GraphQL запрос
4. Сервер: Парсинг ответа
5. Сервер → Клиент: JSON с матчами
6. Клиент: Отрисовка списка
```

### 3.3. Алгоритм отправки сообщения

```
1. Клиент: Ввод текста, нажатие "Отправить"
2. Клиент → Сервер: POST /api/coaching/conversations/{id}/
   Body: { "text": "..." }
3. Сервер: Создание объекта Message
4. Сервер: Обновление updated_at у Conversation
5. Сервер → Клиент: JSON созданного сообщения
6. Клиент: Добавление в список, прокрутка
```
