## 1. Введение

### 1.1. Назначение программы

**DotaTrener** — это приложение для поиска и взаимодействия с тренерами по Dota 2. С помощью программы вы можете:

- Найти тренера по рейтингу, цене и специализации;
- Просматривать статистику своих матчей;
- Общаться с тренерами через встроенный мессенджер;
- Оставлять отзывы о тренерах.

### 1.2. Системные требования

**Для Web-версии:**
- Браузер: Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- Подключение к интернету

**Для Android:**
- Версия Android: 5.0+
- Подключение к интернету

## 2. Установка и запуск

### 2.1. Web-версия

1. Откройте браузер (Chrome, Firefox, Safari или Edge)
2. Перейдите по адресу: `http://83.222.16.188`
3. Приложение загрузится автоматически

### 2.2. Android-версия

1. Скачайте APK-файл установщика
2. Откройте файл на устройстве Android
3. Разрешите установку из неизвестных источников (если требуется)
4. Нажмите "Установить"
5. После установки нажмите "Открыть"

## 3. Работа с программой

### 3.1. Авторизация

#### Вход через Steam

1. На главном экране нажмите **"Аккаунт"**
2. Нажмите **"Войти через Steam"**
3. Вы будете перенаправлены на сайт Steam
4. Войдите в свой аккаунт Steam (если ещё не вошли)
5. Подтвердите авторизацию приложения
6. Вы будете перенаправлены обратно в приложение

> **Примечание:** Приложение получит доступ только к публичной информации вашего профиля Steam (ник, аватар, Steam ID).

#### Привязка Steam аккаунта

1. Перейдите в раздел **"Привязать Steam"**
2. Нажмите **"Войти через Steam"**
3. Подтвердите привязку

### 3.2. Профиль

#### Просмотр профиля

1. На главном экране нажмите **"Аккаунт"**
2. Вы увидите информацию:
   - Никнейм и аватар
   - Steam ID
   - Текущий MMR и ранг
   - Статус тренера

#### Редактирование имени

1. В разделе **"ПРОФИЛЬ"** нажмите на поле с именем
2. Введите новое имя
3. Нажмите **"Сохранить"**

#### Загрузка аватара

1. В разделе **"ПРОФИЛЬ"** нажмите на аватар или **"Загрузить аватарку"**
2. Выберите файл изображения (JPEG или PNG)
3. Обрежьте изображение (перетаскивайте для позиционирования)
4. Нажмите **"Обрезать"**
5. Аватар загрузится автоматически

### 3.3. Просмотр матчей

#### Список матчей

1. На главном экране нажмите **"Мои матчи"**
2. Отобразится список последних 20 матчей с:
   - Героем
   - Результатом (победа/поражение)
   - KDA (убийства/смерти/ассисты)
   - GPM/XPM
   - Длительностью

#### Детали матча

1. Нажмите на любой матч в списке
2. Откроется экран с детальной информацией:
   - Все 10 игроков с героями
   - Статистика каждого игрока
   - График нетворса
   - Сравнение урона
   - Сборки (билды) героев

### 3.4. Каталог тренеров

#### Поиск тренера

1. На главном экране нажмите **"Тренеры"**
2. Просмотрите список тренеров с:
   - Аватаром и именем
   - Специализацией
   - Рейтингом (1-5 звёзд)
   - Рангом (Medal)
   - Количеством услуг и ценой

#### Страница тренера

1. Нажмите на любого тренера в списке
2. Просмотрите:
   - Подробное описание (bio)
   - Социальные сети (Telegram, Discord и др.)
   - Список услуг с ценами
   - Видео-обзоры
   - Отзывы других пользователей

### 3.5. Запись на услугу

1. На странице тренера выберите услугу
2. Нажмите **"Связаться"**
3. Автоматически создастся беседа с первым сообщением
4. Вы будете перенаправлены в чат

### 3.6. Чат

#### Просмотр сообщений

1. На главном экране нажмите **"Аккаунт"** → **"Сообщения"**
2. Выберите беседу из списка
3. Просмотрите историю сообщений

#### Отправка сообщения

1. В поле ввода введите текст сообщения
2. Нажмите кнопку отправки (→)
3. Сообщение отправится мгновенно

### 3.7. Отзывы

#### Оставить отзыв

1. Перейдите на страницу тренера
2. Прокрутите вниз до раздела **"ОТЗЫВЫ"**
3. Выберите оценку (1-5 звёзд)
4. Введите текст отзыва
5. Нажмите **"Отправить"**

### 3.8. Услуги тренера (для тренеров)

#### Добавление услуги

1. На главном экране нажмите **"Аккаунт"** → **"Мои услуги"**
2. Нажмите **"+ Добавить"**
3. Заполните форму:
   - Название
   - Описание
   - Цена ($)
   - Длительность (мин)
4. Нажмите **"Сохранить"**

#### Редактирование услуги

1. В списке услуг нажмите **"Изменить"** рядом с услугой
2. Внесите изменения
3. Нажмите **"Сохранить"**

#### Удаление услуги

1. В списке услуг нажмите **"Удалить"** рядом с услугой
2. Подтвердите удаление

### 3.9. Видео тренера (для тренеров)

#### Загрузка видео

1. Перейдите на вкладку **"Видео"** в разделе услуг
2. Нажмите **"+ Добавить"**
3. Заполните форму:
   - Название
   - Описание
   - Файл видео (макс. 600 МБ) или URL
   - Длительность (сек)
   - Цена ($)
4. Нажмите **"Сохранить"**

#### Просмотр видео

1. На странице тренера выберите видео
2. Нажмите **"Смотреть"** или используйте встроенный плеер

### 3.10. Stratz API токен

Для просмотра статистики матчей необходим Stratz API токен:

1. Перейдите на [stratz.com/api](https://stratz.com/api)
2. Войдите через Steam
3. Скопируйте токен
4. В приложении перейдите в **"Аккаунт"** → **"Stratz API токен"**
5. Вставьте токен и нажмите **"Сохранить"**

### 3.11. Становление тренером

1. Перейдите в **"Аккаунт"**
2. В разделе **"ТРЕНЕР"** нажмите **"Отправить заявку"**
3. Введите сообщение:
   - Ваш опыт в Dota 2
   - Ранг
   - Специализация
   - Почему хотите стать тренером
4. Нажмите **"Отправить заявку"**
5. Дождитесь рассмотрения администратором

## 5. Возможные ошибки и их устранение

### 5.1. Ошибки авторизации

| Ошибка | Причина | Решение |
|--------|---------|---------|
| "Не удалось войти через Steam" | Проблемы соединением с Steam | Проверьте подключение к интернету и повторите попытку |
| "Steam ID не найден" | Аккаунт Steam не привязан | Привяжите Steam аккаунт в настройках |

### 5.2. Ошибки загрузки данных

| Ошибка | Причина | Решение |
|--------|---------|---------|
| "Ошибка загрузки" | Сервер недоступен | Подождите несколько минут и повторите попытку |
| "Нет данных" | Stratz токен не установлен | Установите Stratz API токен в настройках |
| "Токен истёк" | Время жизни токена истекло | Войдите заново через Steam |

### 5.3. Ошибки отправки

| Ошибка | Причина | Решение |
|--------|---------|---------|
| "Не удалось отправить" | Проблемы соединением | Проверьте подключение к интернету |
| "Сообщение пустое" | Не введён текст | Введите текст сообщения |
| "Цена не указана" | Не введена цена услуги | Укажите цену в поле "Цена" |

### 5.4. Ошибки загрузки файлов

| Ошибка | Причина | Решение |
|--------|---------|---------|
| "Файл слишком большой" | Превышен лимит размера | Используйте файл меньшего размера |
| "Неподдерживаемый формат" | Неверный формат файла | Используйте JPEG/PNG для аватара, MP4/WebM для видео |
| "Ошибка загрузки видео" | Проблемы с сетью | Проверьте подключение и повторите попытку |

### 5.5. Общие ошибки

| Ошибка | Причина | Решение |
|--------|---------|---------|
| Белый экран | Ошибка JavaScript | Обновите страницу (F5 / Ctrl+R) |
| Приложение зависает | Нехватка памяти | Закройте другие вкладки/приложения |
| Медленная загрузка | Медленный интернет | Проверьте скорость подключения |
