## 3. Настройка окружения разработки

### 3.1. Требования к системе

- **ОС:** Windows 10+, macOS 10.14+, Ubuntu 20.04+
- **Node.js:** 18.0+ (рекомендуется 20.x)
- **Python:** 3.10+
- **Git:** 2.30+
- **Диск:** 10 ГБ+ свободного места

### 3.2. Установка зависимостей

#### Клиент (Frontend)

```bash
# Клонирование репозитория
git clone https://github.com/username/DotaTrener.git
cd DotaTrener/client

# Установка зависимостей
npm install

# Запуск в режиме разработки (Web)
npm run web

# Запуск в режиме разработки (Android)
npm run android
```

#### Сервер (Backend)

```bash
# Переход в каталог сервера
cd DotaTrener/DotaTrener

# Создание виртуального окружения
python -m venv venv

# Активация виртуального окружения
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

# Установка зависимостей
pip install -r ../requirements.txt

# Создание .env файла
cp .env.example .env

# Применение миграций
python manage.py migrate

# Создание суперпользователя
python manage.py createsuperuser

# Запуск сервера разработки
python manage.py runserver
```

### 3.3. Переменные окружения

Файл `.env` должен содержать:

```env
# Django
DEBUG=True
SECRET_KEY=your-secret-key-here
ALLOWED_HOSTS=localhost,127.0.0.1

# Steam API
STEAM_API_KEY=your-steam-api-key

# Stratz API
STRATZ_API_TOKEN=your-stratz-token

# База данных (для PostgreSQL)
# DB_NAME=dotatrener
# DB_USER=postgres
# DB_PASSWORD=password
# DB_HOST=localhost
# DB_PORT=5432
```

### 3.4. Конфигурация API

Файл `client/src/lib/api.ts`:

```typescript
const HOST = "83.222.16.188";  // IP сервера

export const API_BASE = `http://${HOST}/api/coaching`;
export const API_ROOT = `http://${HOST}`;
export const API_HEROES = `${API_BASE}/heroes/`;
export const API_STRATZ_META = `http://${HOST}/api/stratz/hero-meta/`;
```

Для локальной разработки замените `HOST` на `localhost:8000`.

#### Nginx конфигурация

```nginx
server {
    listen 80;
    server_name 83.222.16.188;

    # API
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # Static files
    location /static/ {
        alias /var/www/dotatrener/static/;
    }

    # Media files
    location /media/ {
        alias /var/www/dotatrener/media/;
    }

    # Web app (React Native Web)
    location / {
        root /var/www/dotatrener/client/dist;
        try_files $uri $uri/ /index.html;
    }
}
```

### 4.5. Добавление нового API-эндпоинта

1. Добавьте маршрут в `coaching/urls.py`:

```python
urlpatterns = [
    # ... существующие маршруты
    path('new-endpoint/', views.new_endpoint, name='new-endpoint'),
]
```

2. Создайте представление в `coaching/views.py`:

```python
from rest_framework.decorators import api_view, permission_classes
from rest_framework.permissions import IsAuthenticated
from rest_framework.response import Response

@api_view(['GET'])
@permission_classes([IsAuthenticated])
def new_endpoint(request):
    # Логика обработки
    return Response({"data": "value"})
```

3. Используйте на клиенте:

```typescript
import axios from "axios";
import { API_BASE as API } from "@/lib/api";
import { getToken } from "@/lib/token-storage";

const fetchData = async () => {
  const token = getToken();
  const res = await axios.get(`${API}/new-endpoint/`, {
    headers: { Authorization: `Token ${token}` },
  });
  console.log(res.data);
};
```

## 7. Известные проблемы и ограничения

| Проблема | Описание | Решение |
|----------|----------|---------|
| CORS | Ошибки CORS при локальной разработке | Используйте proxy в `package.json` |
| Размер видео | Ограничение 600 МБ на видео | Разбейте на части или используйте URL |
| Реалтайм чат | Нет WebSocket (опрос каждые 30 сек) | Реализовать WebSocket в будущем |
| Пагинация | Матчи загружаются без пагинации | Добавить бесконечную прокрутку |
